# Resurse333 — объединённый ресурс-пакет (RU) для Minecraft 1.21.11

Готовый пакет: **`Resurse333-merged-RU-1.21.11.zip`** (≈6,4 МБ, 4203 файла).
Формат ресурс-паков: **75** (`pack_format: 75`, `min/max_format: [75, 0]`) — это Minecraft **1.21.11**.

Механизм переименования предметов в анвиле **удалён** — кастомные предметы
задаются через конфиг плагина: **`items.yml`** содержит запись для **каждой
модели пакета** (816 штук) и подключена в самом пакете через штатный
`custom_model_data` — **OptiFine не требуется**.

## Что внутри

В один пакет объединены все 7 исходных пакетов из этого репозитория:

| Исходный пакет | Что даёт | Автор |
|---|---|---|
| Blades of War 2 v2.1 | Модели и текстуры оружия (мечи, топоры, кирки, копья, луки, щиты) | Zerotekz |
| Blades Of Majestica | 119 моделей клинков | — |
| ALs-Mob-Weapons 1.3 | Особые модели оружия для мобов (работает без переименования — по типу сущности) | — |
| Dee's Extended Equipment | Оружие-инструменты, иконки доспехов, короны; рендер доспехов на игроке — OptiFine CIT | Deesaster_ + Vanilla Tweaks |
| Teyvat Weapon Collection 1.4.1 | 36 предметов Genshin Impact (лук/арбалет/мечи/копья) — перенесено в ванильные модели | Raycifer |
| More Hats 1.1 | Модели и текстуры 30 шлемов | Ililii_ и Hot_doggy13 |
| Somies Variable Hats | 45 шлемов с русскими названиями — перенесено в ванильные модели | Somies |

## Установка

1. Скопируйте `Resurse333-merged-RU-1.21.11.zip` в папку `resourcepacks`.
2. Включите пакет в списке ресурс-паков (для 1.21.11 предупреждений о версии быть не должно).
3. **Моды не нужны.** Всё содержимое пакета (включая шляпы Somies, оружие Teyvat,
   иконки доспехов Dee's) подключено ванильным механизмом `custom_model_data`
   и работает чистым клиентом.
4. **Единственное исключение — рендер доспехов Dee's на игроке** (барбуты,
   кирасы, короны и т.п. как текстуры брони на персонаже): это OptiFine-CIT
   (`type=armor`), ванильный клиент такие подмены не умеет. Для них на
   Fabric/Quilt поставьте мод **CIT Resewn** (или OptiFine). Без мода доспехи
   доступны как обычные предметы с кастомной **иконкой в инвентаре**
   (иконки подключены ванильно), а на игроке отображаются стандартной текстурой.
5. Логика оружия мобов (ALs-Mob-Weapons) встроена в пакет и работает **без модов**.

## Конфиг плагина — `items.yml` (все модели пакета)

В корне репозитория лежит **`items.yml`** — полный скрипт кастомных предметов:
**816 записей**. Нумерация `custom-model-data`: **1001–1693** — модели исходных
паков, **1694–1816** — перенесённые из OptiFine-CIT части (Somies, Teyvat,
иконки Dee's).

```yaml
items:
  abominableblade:                # id = модель пакета
    material: DIAMOND_SWORD       # предмет, на который надевается модель
    name: 'Мерзкий Клинок'        # русское название
    lore:
      - '&7Модель: abominableblade'
      - '&8Пакет: Blades Of Majestica'
    custom-model-data: 1001       # номер модели (уникален в скрипте)
    enchants: {}
    recipe:
      enabled: false
      shape: []
      ingredients: {}
```

**Подключение сделано в самом пакете.** В `assets/minecraft/items/*.json`
(**65 файлов**) добавлен узел `range_dispatch` по `minecraft:custom_model_data`
(формат 1.21.4+): каждому номеру из скрипта соответствует модель пакета,
исходное содержимое файла сохранено как `fallback` (логика мобов ALs и
ванильное поведение не потеряны). Составные предметы подключены целыми
структурами: луки — со стягиванием, арбалеты — с зарядкой и типом снаряда,
щиты — с блоком.

Что в скрипт **не входит** (составные кадры и внутренности, сами модели
как предметы уже покрыты):

| Группа | Почему |
|---|---|
| Шаблоны-родители `models/*_template` | вспомогательные, не предметы |
| Кадры анимации (`*_pulling_*`, `*_blocking`, `*_reloading_*`, кадры часов/компаса) | входят в составные предметы (луки, щиты, арбалеты, часы) |
| Состояния арбалетов, заброса удочки, Teyvat-loading/loaded | состояния моделей выше |
| Часы и компас (`clock`, `compass`, `copper_*`, `golden_compass`, `iron_clock`) | их дефайны принадлежат игре, динамические кадры остаются за игрой |

## Что было сделано при сборке

1. **Объединение** — все 7 паков слиты в один. Конфликтные файлы решены так:
   - 31 файл `assets/minecraft/items/*.json` — логика мобов ALs
     (`select` по `context_entity_type`) встроена как основная ветка,
     ванильная модель как запасная; дубликат `Cyber Katana` устранён;
   - `pack.mcmeta` — новый, формат 75 для 1.21.11, описание по-русски;
   - `pack.png` — обложка Blades of War 2;
   - `optifine/emissive.properties` — идентичен во всех паках;
   - `textures/misc/pumpkinblur.png` — полностью прозрачная версия (удобно для шлемов).
2. **Переименование убрано** — из 48 файлов `items/*.json` удалены все ветки,
   сопоставляющие модели по `custom_name` (и английские, и русские варианты);
   файл со списком названий удалён. Предметы теперь выдаются через плагин.
3. **Скрипт всех моделей** — `items.yml` собран автоматически по инвентарю
   моделей: названия — из исходных when-пар (EN→RU), материал — по
   происхождению модели, для Dee's — по `.properties`.
4. **Части OptiFine-CIT переведены в ванильные модели**:
   - 45 шляп Somies → `models/somies/*.json` + русские имена из `rus/`-правил;
   - 36 предметов Teyvat → `models/teyvat/<группа>/` (луки со стягиванием,
     катализаторы-арбалеты с зарядкой — целыми структурами);
   - 42 иконки доспехов Dee's → `models/dees/armor/*.json` (generated-модели
     из icon-текстур) на материалах `*_HELMET/CHESTPLATE/LEGGINGS/BOOTS/…`;
   - исходные `optifine/cit/**` сохранены без изменений (работают при
     наличии CIT Resewn/OptiFine как раньше).
5. **Подключение CMD** — во все `items/*.json` добавлен `range_dispatch` по
   `minecraft:custom_model_data` (порог = номер − 0.5), `fallback` =
   исходное содержимое файла.
6. **Русский язык сохранён там, где он не зависит от переименования**:
   описание пакета, `credits.txt`; в CIT-частях Teyvat и Dee's (508 файлов)
   русские альтернативы regex-совпадений оставлены.
7. **Проверка** — все JSON пакета валидны; все ссылки моделей и текстур
   внутри подключённых записей проверены — битых нет; каждый
   `custom-model-data` скрипта присутствует в дефайне своего материала;
   все 816 названий на русском.

## Особенности и ограничения

- Луки ALs по-прежнему реагируют на тип держащего моба (ветка в `fallback`);
  номер из скрипта работает поверх этого для обычных предметов.
- Рендер доспехов Dee's **на игроке** — единственное, что требует
  CIT Resewn/OptiFine (см. «Установка», п. 4); иконки и всё остальное
  работают ванильно.
- Часы/компас в скрипте не подключены: их динамические дефайны принадлежат
  игре, косметические варианты работают через OptiFine CIT, как и раньше.
- Состояние заброса уудочки при выдаче через CMD не переключается
  (ванильная логика `items/fishing_rod.json` заменена дефайном пакета).
- Оригинальные zip-файлы пакетов сохранены в репозитории как есть.
