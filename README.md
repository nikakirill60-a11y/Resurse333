# Resurse333 — объединённый ресурс-пакет (RU) для Minecraft 1.21.11

Готовый пакет: **`Resurse333-merged-RU-1.21.11.zip`** (≈6,0 МБ, 3863 файла).
Формат ресурс-паков: **75** (`pack_format: 75`, `min/max_format: [75, 0]`) — это Minecraft **1.21.11**.

Механизм переименования предметов в анвиле **удалён** — кастомные предметы
задаются через конфиг плагина: **`items.yml`** содержит запись для **каждой
модели пакета** и подключена в самом пакете (см. ниже).

## Что внутри

В один пакет объединены все 7 исходных пакетов из этого репозитория:

| Исходный пакет | Что даёт | Автор |
|---|---|---|
| Blades of War 2 v2.1 | Модели и текстуры оружия (мечи, топоры, кирки, копья, луки, щиты) | Zerotekz |
| Blades Of Majestica | 119 моделей клинков | — |
| ALs-Mob-Weapons 1.3 | Особые модели оружия для мобов (работает без переименования — по типу сущности) | — |
| Dee's Extended Equipment | Доспехи, шлемы, инструменты-оружия (OptiFine CIT) | Deesaster_ + Vanilla Tweaks |
| Teyvat Weapon Collection 1.4.1 | Луки из Genshin Impact (OptiFine CIT) | Raycifer |
| More Hats 1.1 | Модели и текстуры 30 шлемов | Ililii_ и Hot_doggy13 |
| Somies Variable Hats | 45 шлемов (OptiFine CIT), с русскими названиями | Somies |

## Установка

1. Скопируйте `Resurse333-merged-RU-1.21.11.zip` в папку `resourcepacks`.
2. Включите пакет в списке ресурс-паков (для 1.21.11 предупреждений о версии быть не должно).
3. Для частей **Teyvat / Dee's / Somies** (OptiFine CIT) на 1.21.11 потребуется мод
   **CIT Resewn** (Fabric/Quilt) или OptiFine с поддержкой этой версии.
4. Логика оружия мобов (ALs-Mob-Weapons) встроена в пакет и работает **без модов**.

## Конфиг плагина — `items.yml` (все модели пакета)

В корне репозитория лежит **`items.yml`** — полный скрипт кастомных предметов:
**693 записи, по одной на каждую содержательную модель пакета** (всего в пакете
999 JSON-моделей). Нумерация `custom-model-data` идёт с **1001**.

```yaml
items:
  abominableblade:                # id = модель пакета
    material: DIAMOND_SWORD       # предмет, на который надевается модель
    name: 'Мерзкий Клинок'        # русское название
    lore:
      - '&7Модель: abominableblade'
      - '&8Пакет: Blades Of Majestica'
    custom-model-data: 1001       # номер модели (уникален в скрипте)
    enchants: {}
    recipe:
      enabled: false
      shape: []
      ingredients: {}
```

**Подключение сделано в самом пакете.** В `assets/minecraft/items/*.json`
добавлен узел `range_dispatch` по `minecraft:custom_model_data`
(формат 1.21.4+): каждому номеру из скрипта соответствует модель пакета,
исходное содержимое файла сохранено как `fallback` (логика мобов ALs и
ванильное поведение не потеряны). Подключено **50 предметных файлов** —
все существующие в пакете плюс `fishing_rod` и `goat_horn`.

Выдавайте предмет плагином с `material` и `custom-model-data` из скрипта —
модель отобразится.

Что исключено из скрипта (306 файлов) и почему:

| Группа | Кол-во | Почему |
|---|---|---|
| Шаблоны-родители `models/*_template` | 7 | вспомогательные, не предметы |
| Кадры анимации (`*_pulling_*`, `*_blocking`, `*_reloading_*`, кадры часов/компаса) | 257 | входят в составные предметы (луки, щиты, арбалеты, часы) |
| Состояния арбалетов и заброса удочки | 36 | состояния моделей выше |
| Часы и компас (`clock`, `compass`, `copper_*`, `golden_compass`, `iron_clock`) | 6 | их дефайны принадлежат игре, косметика работает через OptiFine CIT |

Отдельно: модели из OptiFine-CIT (Teyvat 36, Somies) лежат в
`assets/minecraft/optifine/cit/**` и подключаются только через CIT — их нет
в скрипте, они не относятся к предметным моделям.

## Что было сделано при сборке

1. **Объединение** — все 7 паков слиты в один. Конфликтные файлы решены так:
   - 31 файл `assets/minecraft/items/*.json` — логика мобов ALs
     (`select` по `context_entity_type`) встроена как основная ветка,
     ванильная модель как запасная; дубликат `Cyber Katana` устранён;
   - `pack.mcmeta` — новый, формат 75 для 1.21.11, описание по-русски;
   - `pack.png` — обложка Blades of War 2;
   - `optifine/emissive.properties` — идентичен во всех паках;
   - `textures/misc/pumpkinblur.png` — полностью прозрачная версия (удобно для шлемов).
2. **Переименование убрано** — из 48 файлов `items/*.json` удалены все ветки,
   сопоставляющие модели по `custom_name` (и английские, и русские варианты);
   файл со списком названий удалён. Предметы теперь выдаются через плагин
   (см. `items.yml`).
3. **Скрипт всех моделей** — `items.yml` собран автоматически по инвентарю
   моделей: названия взяты из исходных паков (EN→RU пары переименования),
   материал — по происхождению модели, для Dee's — по `.properties`
   (`items=`/`model=`). Составные предметы (луки со стягиванием, щиты с
   блоком, арбалеты с зарядкой) подключены целыми структурами.
4. **Подключение CMD** — во все `assets/minecraft/items/*.json` добавлен
   `range_dispatch` по `minecraft:custom_model_data` (порог = номер − 0.5),
   `fallback` = исходное содержимое файла.
5. **Русский язык сохранён там, где он не зависит от переименования**:
   описание пакета, `credits.txt`; в CIT-частях Teyvat (36) и Dee's (508 файлов)
   русские альтернативы regex-совпадений оставлены.
6. **Проверка** — все JSON валидны (items: 50 файлов, модели: 999);
   770 ссылок внутри подключённых записей проверены, битых нет;
   каждый `custom-model-data` скрипта присутствует в дефайне своего материала.

## Особенности и ограничения

- Луки ALs по-прежнему реагируют на тип держащего моба (ветка в `fallback`);
  номер из скрипта работает поверх этого для обычных предметов.
- Часы/компас в скрипте не подключены: их дефайны (динамические стрелки)
  принадлежат игре, а косметические варианты (`copper_clock`,
  `golden_compass`…) работают через OptiFine CIT, как и раньше.
- Состояние заброса уудочки при выдаче через CMD не переключается
  (ванильная логика `items/fishing_rod.json` заменена дефайном пакета).
- Части OptiFine-CIT (Dee's, Teyvat, Somies) сохранены со своими внутренними
  правилами сопоставления .properties — они не относятся к анвиль-механике пакета.
- Оригинальные zip-файлы пакетов сохранены в репозитории как есть.
